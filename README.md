# Tabular Foundation Model Benchmark

An early AIMultiple comparison of SAP-RPT-1-OSS, LightGBM and CatBoost on tabular prediction. The project examines classification and regression alongside training time, inference time and compute requirements.

> [Read the tabular models benchmark on AIMultiple](https://aimultiple.com/tabular-models)

## Original project scope

- SAP-RPT-1-OSS as a tabular foundation model, with LightGBM and CatBoost as gradient-boosting baselines.
- Binary classification, multiclass classification and regression datasets.
- Shared cross-validation splits and task-specific evaluation metrics.
- Runtime and resource measurements alongside predictive performance.

Dataset size and feature types are part of the comparison. Cross-validation provides separate training and evaluation partitions for every model.

## Published research

AIMultiple has since expanded the article to cover a broader model comparison with a different evaluation setup. Its results and statistical analysis apply to that expanded study.

The earlier SAP-RPT-1-OSS project is summarized here without transferring its scores to the newer comparison.
